# Daily Sticky (دايلي ستيكي) — v0.5.0

تطبيق ملاحظة يومية ذكية لسطح المكتب تعمل كأداة هادئة ومثبتة فوق خلفية سطح المكتب دون إزعاج سير العمل.

---

## الميزات الأساسية (Core Features)

- **طبقة سطح المكتب الذكية (Desktop Layer)**: تظل الملاحظة مثبتة بهدوء على سطح المكتب خلف النوافذ العادية مع استبعادها من شريط المهام (Taskbar) ومبدل النوافذ (Alt+Tab).
- **التدوير اليومي للمهام (Daily Rollover)**: ترحيل تلقائي وذكي للمهام غير المنجزة عند منتصف الليل مع الحفاظ على سجل الأيام السابقة غير قابل للتعديل.
- **الحكمة اليومية والتقويم المزدوج**: عرض التاريخ بالتقويمين الهجري والميلادي مع اختيار دوري للأقوال المأثورة.
- **تفاعل متكامل للمهام (Task UX)**: قائمة سياقية بالزر الأيمن لتعديل المهام، حذفها، أو تنظيف المهام المنجزة، مع تمييز مرئي دقيق للأولويات.
- **سجل الأيام السابقة (History UI)**: نافذة مخصصة لاستعراض تاريخ الأيام السابقة ونسبة الإنجاز للقراءة فقط.
- **حفظ الموقع والحجم (Geometry Persistence)**: حفظ تلقائي لموقع وأبعاد الملاحظة واستعادتها بأمان حتى في بيئات الشاشات المتعددة.
- **صينية النظام وزر الخروج (Tray & Exit Control)**: أيقونة صينية نظام للتحكم بإظهار وإخفاء النافذة، وزر إغلاق علوي يساري للخروج الكامل.
- **التشغيل مع ويندوز (Windows Startup)**: خيار تشغيل تلقائي اختياري عبر سجل النظام (Registry) دون الحاجة لصلاحيات مدير النظام (Admin).

## متطلبات التشغيل (Requirements)

- **نظام التشغيل**: Microsoft Windows 10 / 11 (64-bit).
- **بيئة التطوير**: Python 3.10+ مع PySide6.

---

## التشغيل في بيئة التطوير (Development Setup)

1. إنشاء وتفعيل البيئة الافتراضية:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```
2. تثبيت الحزم المطلوبة:
   ```bash
   pip install -r requirements.txt
   pip install -r requirements-dev.txt
   ```
3. تشغيل التطبيق:
   ```bash
   python run.py
   ```
4. تشغيل الاختبارات:
   ```bash
   python scripts/run_all_backend_tests.py
   ```

---

## بناء الحزمة ومثبت التثبيت (Packaging & Installer)

يستخدم المشروع **PyInstaller** لإنشاء نسخة تنفيذية مجمعة (onedir)، ومثبت **Inno Setup** لتوليد ملف التثبيت النهائي:

1. لتشغيل السكربت التلقائي للبناء (PowerShell):
   ```powershell
   powershell -ExecutionPolicy Bypass -File packaging/build_windows.ps1
   ```
2. يتم إنشاء النسخة التنفيذية في:
   `dist/DailySticky/DailySticky.exe`
3. يتم إنشاء ملف التثبيت في:
   `dist/installer/DailySticky-Setup-0.5.0.exe`

## موقع بيانات المستخدم (User Data Storage)

يتم تخزين قاعدة بيانات SQLite الخاصة بالمستخدم في مسار مستقل لا يتأثر بالتحديثات أو إزالة التطبيق:
```
%LOCALAPPDATA%\DailySticky\daily_sticky.db
```

## قيود معروفة (Known Deferred Issues)

- **Win+D (Show Desktop)**: اختصار ويندوز `Win+D` يقوم بإخفاء الملاحظة مؤقتاً خلف سطح المكتب التابع للمستكشف (Explorer Progman). يمكن إعادة إظهار الملاحظة بالنقر على أيقونة صينية النظام أو النقر على سطح المكتب. هذا السلوك معروف ومؤجل للإصدارات اللاحقة.
